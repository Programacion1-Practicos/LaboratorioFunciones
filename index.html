return
Devuelve un valor y termina el método. El valor debe coincidir con el tipo de retorno.
Usar el resultado
El valor que devuelve una función se puede guardar en una variable del mismo tipo, imprimir o usar dentro de una expresión: int r = sumar(2, 3) * 10;
Parámetros y argumentos
Los parámetros se declaran con tipo en la firma; los argumentos son los valores que se pasan en la llamada: sumar(3, 4). Deben coincidir en cantidad, orden y tipo.
Ámbito
Las variables declaradas dentro de un método solo existen ahí. Un int se pasa por valor: modificar el parámetro no cambia la variable original.

En los ejemplos, los métodos están dentro de public class Main; la clase se omite para abreviar.
